CPU model                       : AMD Ryzen 7 6800H with Radeon Graphics (family 0x19, model 0x44, stepping 1)
Microarchitecture               : AMD Zen 3+ ("Rembrandt", FP7 package)
Physical cores                  : 8 (2 CCX x 4 cores)
Logical cores (hardware threads): 16 (SMT2 enabled on every core)
Performance / efficiency cores  : N/A - homogeneous design, all 8 cores are Zen 3+; there is no P/E split
Base clock (GHz)                : 3.20
Max single-core clock (GHz)     : 4.75 (rated boost; sustained under a real FMA loop: 2.38 measured)
All-core clock under load (GHz) : 2.02 (measured from all-core FMA throughput: 495 GFLOP/s / (32 FLOP/cyc x 8 cores))
SIMD instruction set and width  : AVX2 + FMA3, 256-bit (AVX-512 is fused off on Rembrandt); SSE/SSE2/SSE3/SSSE3/SSE4.1/SSE4.2/AVX also present
FMA units per core              : 2 (two 256-bit FMA/FADD pipes, FP0 and FP1)
Vector registers per core       : 16 x 256-bit YMM (16 x 128-bit XMM aliased; no ZMM)
L1 data cache (per core)        : 32 KiB, 8-way, 64 B lines, 2 x 32 B loads + 1 x 32 B store per cycle
L2 cache (size, shared by)      : 512 KiB per core, 8-way, private to that core (not shared)
L3 cache (size, shared by)      : 16 MiB total = 2 x 8 MiB, each 8 MiB shared by the 4 cores of one CCX
Cache line size (bytes)         : 64
RAM size (GB)                   : 16 (2 x 8 GB SO-DIMM, both slots populated)
RAM type, speed (MT/s), channels: DDR5-4800 SODIMM, 4800 MT/s, 2 channels (dual channel, 2 x 64-bit)
Operating system                : Windows 11 Home Single Language, version 26H2, build 26300.9711
Compiler and version            : gcc (MSYS2 UCRT64) 14.1.0, flags -O3 -march=native (-march=native resolves to znver3)
